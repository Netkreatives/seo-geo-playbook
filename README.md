# SEO / GEO Playbook

A working knowledge base for getting small product sites found in Google and in AI answers (ChatGPT, Claude, Gemini, Perplexity). Written from running a portfolio of small app sites through a spam update, and from reading what others have published.

It is short on purpose. Most SEO/GEO advice is the same dozen ideas; this repo keeps the ones that survived contact with real data, and says where each one comes from.

## How to read a claim

Every non-obvious statement carries one of three labels:

| Label | Meaning |
| --- | --- |
| **observed** | Seen in our own Search Console, crawl or AI-answer data. Small samples; treat as a case, not a law. |
| **sourced** | Stated by a third party we link to. Not independently tested by us. |
| **rule of thumb** | A threshold people repeat. Useful as a starting point, never as a fact. |

Platform behaviour changes. Check vendor documentation before acting on anything about crawlers, structured data or rich results.

## Suggested order

1. Foundation audit, Bing Webmaster Tools, first run of buyer questions.
2. Search Console, sitemap, a small set of consistent directory listings.
3. One decision page at a time, each with first-party evidence.
4. After about three months of data: start optimising from Search Console.
